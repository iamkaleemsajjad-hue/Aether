# Kaggle Benchmark Runbook — Aether Runtime (3-Engine Setup)

Complete, cell-by-cell instructions for running the multi-engine benchmark on a
**Kaggle GPU notebook (2× Tesla T4, 4 vCPU, ~31 GiB RAM)**.

> **Aether is compiled from the cloned source code** — not from a pip release.
> The active engines measured are:
> 1. `transformers` — HuggingFace Transformers on PyTorch eager (reference baseline)
> 2. `pytorch_native` — Hand-written PyTorch decode loop, same weights as baseline
> 3. `aether` — Aether Runtime AOT compiler + runtime (subject under test)

---

## Kaggle Notebook Settings

In the right-hand panel of your Kaggle notebook:
- **Accelerator**: `GPU T4 x2`
- **Language**: `Python`
- **Internet**: `On` (required for git clone and model weights download)
- **Persistence**: `Files only` (optional, preserves output files across sessions)

## Cell 2 — Verify Environment & CUDA Detection

```python
assert "/kaggle/working/aether" in aether.__file__, "Aether must be loaded from cloned source!"
```

## Cell 5 — Display Benchmark Report & View Results

Display the generated markdown report directly inside your Kaggle notebook:

```python
from IPython.display import Markdown, display
from pathlib import Path

report_path = Path("/kaggle/working/benchmark_results/reports/BENCHMARK_REPORT.md")
if not report_path.exists():
    # Fallback to smoke run if full run wasn't executed
    report_path = Path("/kaggle/working/bench_smoke/reports/BENCHMARK_REPORT.md")

if report_path.exists():
    display(Markdown(report_path.read_text(encoding="utf-8")))
else:
    print("Report file not found. Check output directory.")
```

## Cell 6 — Preview Generated Comparison Charts

View the latency and throughput charts generated by the benchmark:

```python
import glob
import matplotlib.pyplot as plt
import matplotlib.image as mpimg

graph_dir = "/kaggle/working/benchmark_results/graphs"
charts = sorted(glob.glob(f"{graph_dir}/*.png"))

if not charts:
    charts = sorted(glob.glob("/kaggle/working/bench_smoke/graphs/*.png"))

print(f"Found {len(charts)} chart(s):")
for chart_path in charts:
    print(f"Displaying: {chart_path}")
    img = mpimg.imread(chart_path)
    plt.figure(figsize=(10, 6))
    plt.imshow(img)
    plt.axis('off')
    plt.show()
```
